# Security

This repository is a sanitized publication of a private homelab project.

## Sensitive information

Do not commit:

- passwords or authentication data;
- private keys or API tokens;
- production configuration files;
- real private-network addresses;
- production SQLite databases;
- logs or operational snapshots;
- personal data;
- game, ISO or PKG content.

Use `config/config.example.ini` only as a template.

## Reporting

If you identify a vulnerability or accidental exposure of sensitive information, avoid publishing the sensitive value in a public issue.

Use GitHub private vulnerability reporting when available, or contact the repository maintainer privately through the GitHub profile.
